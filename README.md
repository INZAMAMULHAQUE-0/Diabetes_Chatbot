# Diabetes Prediction Chatbot 🩺

A conversational AI assistant that assesses diabetes risk through natural dialogue using machine learning.

## Purpose
This tool helps users:
- Understand key diabetes risk factors
- Get instant preliminary risk assessment
- Encourage proactive healthcare decisions
- Provide educational value about diabetes indicators

## Use Cases
- **Personal health screening**: Quick self-assessment
- **Clinical settings**: Preliminary patient screening
- **Health education**: Demonstrates diabetes risk factors
- **Telemedicine**: Remote patient evaluation

## Key Features
- Natural Q&A interface
- Medical-grade prediction model
- Instant risk probability
- Mobile-friendly design

## Technology Stack
- Python + Streamlit (frontend)
- Scikit-learn (ML model)
- HDF5/Pickle (model persistence)
